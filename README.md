## What Was Updated From Part 1

- Added a complete multi-page vehicle-services website with shared navigation.
- Added vehicle listings with images, prices, specifications, features, and enquiry-cart forms.
- Added vehicle search controls and a comparison table on the homepage.
- Added finance, test-drive, contact, customer-review, gallery, cart, and references pages.
- Added a shared stylesheet with a consistent colour palette, responsive navigation, styled panels, tables, forms, buttons, images, and footer.
- Added responsive behaviour for smaller screens so tables and navigation remain usable on mobile devices.
- Added image alt text and reference links for the vehicle content.

## Run Locally

1. Download or clone this repository.
2. Open `index.html` in a web browser.

No build tools or external dependencies are required.

- HTML5
